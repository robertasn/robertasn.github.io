# Pixel & Pocky

A cozy 3D third-person forest game built with zero-dependency WebGL2, starring **Pixel** (long-haired chocolate & tan dachshund) chasing **Pocky** (wild-boar wire-haired dachshund).

## How to Play
Open [`game/index.html`](game/index.html) in any modern browser.

- **Goal**: Chase Pocky through the sunlit forest!
  - **0s – 10s**: Pocky keeps a playful lead and barks at you (if you stop, Pocky stops too and barks to taunt you).
  - **10s – 20s**: Pocky gets tired and the distance shrinks.
  - **20s**: Catch up and bite Pocky's floppy ear to win!
- **Controls**:
  - `W A S D` / Arrow keys — Run & steer
  - `Shift` — Zoomies (sprint)
  - `Space` — Jump (or bite when close)
  - `B` — Bark / Bite Pocky's ear
  - `Mouse Drag` or `Q` / `E` — Orbit camera • `Scroll` — Zoom
  - `R` — Restart • `M` — Toggle sound
